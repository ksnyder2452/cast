The Centralized Automation of Software Tools Framework (CAST) is intended to provide standard, hosted services around locally-\/defined applications (such as DiY Test Frameworks). The following core functionalities are supported


\begin{DoxyItemize}
\item Remote control of client actions
\item Remote storage and distribution of files
\item Integration with REST APIs
\end{DoxyItemize}

This provides several key benefits


\begin{DoxyItemize}
\item Central control of all associated applications
\item Centralized storage of reporting data (for use in dashboards)
\item Simple integration into Pipelines
\item The ability to add future Services into all applications with minimal development effort
\item The ability to compare and contrast data across time, across clients and across platforms
\item The opportunity to both integrate within newly-\/developed applications and within existing applications (with no changes to existing functionality)

\begin{DoxyItemize}
\item Every Client uses it\textquotesingle{}s own unique Message Queue (which is created upon loading client\+\_\+service.\+dll)
\item The table logger is intended to be used in the following manner
\begin{DoxyItemize}
\item reference\+\_\+uuid can be thought of as a Session UUID. Which gives us the ability to easily filter all logs and events to a single reference
\item originator is the UUID of the Service that created the record
\item type is the log type (such as INFO, WARN, ERROR, ACTION)
\item code is intended to reference things like a Database Error Code
\item message is the log description
\item original\+\_\+message is intended to reference things like Stack Traces
\item display\+\_\+name is used to map UUID to an easily understood reference
\item event\+\_\+time\+\_\+dt is the date/timestamp (excluding timezone)
\item order\+\_\+in\+\_\+system is the Primary Key
\end{DoxyItemize}
\item Client State data is stored within the table current\+\_\+state
\item Final Results data is stored within the table final\+\_\+results
\item Every Client must include a cast.\+properties in the root folder containing the following values. See /\+Playwright\+\_\+\+Demo/cast.properties for an example
\begin{DoxyItemize}
\item rabbitmq\+\_\+home
\item rabbitmq\+\_\+port
\item reload\+UUID
\item rabbitmq\+\_\+user
\item rabbitmq\+\_\+pwd
\end{DoxyItemize}
\item Health Check will automatically delete old Queues if the Rabbit\+MQ Controller exists on the same machine (under c\+:\textbackslash{}program files\textbackslash{}\+Rabbitmq Server) 
\end{DoxyItemize}
